规划日期：2026-10-09；最近更新：2026-10-11。状态：阶段 0、阶段 1 和阶段 2 核心体验已实施；阶段 3 已完成设备测试、成员音量、按键发言、影院布局、画面选择、逐成员诊断及六个语音控制器拆分；阶段 4 已完成社区横幅、图片裁切、欢迎页与公告。第十批补齐麦克风、播放与统计的资源隔离，第十一批接通完整 Vue 模板及 Vite 配置类型检查，并修正图片错误事件和源码部署流程。第十二批补齐锁文件打包、暂存验收及事务升级，v1.0.9 本地安装器完成隔离新装、完整与快速升级验收；实体设备与公网验收待完成。完整交付范围与限制见 [OPTIMIZATION-PROGRESS.md](OPTIMIZATION-PROGRESS.md)。

## 产品目标与设计方向

面向朋友群和小型社区，优先改善日常文字聊天、语音与投屏。沿用 Vue、Tailwind 和现有频道布局，采用克制的深色界面与蓝紫品牌强调色；颜色、间距和组件变量已在第三批落地。

视觉目标：聊天正文最醒目，导航和成员信息次之；减少重复头像和操作按钮的视觉占用；连接、上传、阅读和失败状态清楚可辨。登录页暂作为已有样式参考，首轮聚焦主聊天页。

## 阶段 0：可靠性前置工作

范围：附件过期续签、移除固定签名密钥回退、主动退出停止重连、落盘失败保留待保存状态；修正签名篡改测试的随机失败。权限检查、字段校验和断线恢复需要随新增功能同步完善。

验收：历史附件重新读取后获得有效签名；密钥异常不产生可预测签名；退出后无重连计时器；写入失败后恢复可再次落盘；既有测试无随机失败。

依赖：消息重试需要服务端幂等支持；未读与新功能的广播需要重连补拉。基础修复与视觉稿可分别推进，涉及数据的功能在基础修复后交付。

## 阶段 1：主聊天体验（首个交付版本）

### 美术范围

- 建立颜色、文字、间距、圆角、阴影和层级变量；基础间距以 4px 为单位，消息正文默认 14–16px。
- 保留桌面服务器栏、频道栏、聊天区与可收起成员栏；聊天区获得主要宽度。
- 同一作者、同一频道、5 分钟内的连续消息合并头像与昵称；日期、未读分隔线和回复消息打断合并。
- 统一消息工具条、回复预览、附件卡片、错误提示和空状态；时间仍可通过悬停、聚焦或触摸操作查看。
- 桌面悬停显示快捷操作，同时保留键盘入口；移动端长按打开底部操作面板。

### 功能范围

- 仅当用户接近列表底部或主动发送消息时跟随最新消息；阅读历史时显示新消息提示和跳转按钮。
- 顶部加载旧消息后按高度差或锚点恢复位置；切频道不应用旧频道的迟到响应。
- 按账号、频道记录阅读游标；进入频道不立即视为读完，页面可见且实际读到对应位置后才更新。
- 阅读游标使用稳定消息顺序，由服务端持久化并单调更新，支持其他设备同步；升级时为已有成员将历史最新消息保存为基线，新消息到达前初始化新成员基线。
- 当前频道显示未读分隔线，频道列表显示未读标记；断线后补拉消息并恢复订阅，避免重复显示。
- 发送中、失败、重试状态；服务端以 userId + clientMessageId 去重，确认后插入消息。列表内临时消息气泡作为后续交互增强。
- 保存各频道输入草稿；发送失败保留文字、回复信息与附件状态。

主要文件：MessageList.vue、ChatBox.vue、ChannelList.vue、Home.vue、stores/chat.ts、utils/ws.ts、routes/messages.js、models/db.js、types/index.ts。

验收：阅读旧记录时收到消息不跳动；加载历史不回到底部；快速切频道不混入旧响应；离线发送和失败重试不丢内容、不产生重复消息；两台设备的阅读游标不倒退；窄屏与软键盘下输入框可见。

## 阶段 2：消息互动与找回

实施状态：第四批已完成回应、置顶、上下文定位和搜索；第五批已完成成员选择器及跨频道提及提醒。置顶通过完整 `message-updated` 快照和面板刷新同步；重连重新获取服务端状态。当前搜索同时覆盖文字和文件名。

- 表情回应：第一版提供有限常用表情；按 messageId + emoji + userId 唯一记录，点击切换，显示数量和参与者。权限至少要求可查看频道且允许发送消息；服务端校验，不信任客户端人数。
- 消息置顶：要求 manageMessages 权限；置顶面板显示摘要、操作者和时间。删除消息自动清理置顶记录。弹出面板和频道订阅通过独立事件更新，重连重新拉取。
- 回复定位：原消息不在当前分页时按 ID 获取前后上下文；被删除显示明确占位，失去权限不返回内容。
- @成员选择器：保存成员 ID，昵称仅用于展示；@everyone 继续使用现有权限。跨频道提醒由服务端按收件人定向推送，不能依赖仅订阅当前频道的消息广播。
- 消息搜索：第一版为频道内文字关键词与作者筛选，分页并定位结果；必须进行频道权限过滤，限制查询长度与频率。

验收：重复回应不增加重复记录；多个客户端状态一致；无权限用户不能置顶或获取定位上下文；消息删除后关联记录清理；搜索与提醒不泄露不可见频道内容。

依赖：沿用阶段 1 的游标、幂等和补拉能力。搜索可先适配当前存储，但数据量增长前迁移 SQLite 并建索引；不要求首版美术升级同时重写存储。

## 阶段 3：语音与投屏体验

实施状态：第六批已完成设备测试、每人音量和按键发言；第七批已完成影院、共享画面选择、播放器生命周期及逐成员诊断。第九批将连接、协商和投屏拆入 `voice-peers.ts`、`voice-signaling.ts`、`voice-screen-share.ts`；第十批将麦克风、远端音频及本地提示音、统计及电平轮询拆入 `voice-microphone.ts`、`voice-audio-playback.ts`、`voice-statistics.ts`。控制器各自持有资源，通过类型化端口和共享会话标记接线；`voice.ts` 保留页面公开状态、偏好、设备枚举和房间协调。真实 store 回归和本地 WebRTC 检查不能替代实体设备与公网验收。

- 设备采集、PeerConnection、信令、投屏、播放与统计已分离；持续保留离房、重连、账号切换、多个实例和迟到结果的回归。麦克风替换按发送器串行，输出路由核对元素属主；结束的麦克风流重新采集，失败保持仅收听。
- 新增本地麦克风测试与扬声器测试；默认不加入频道、不将测试声音广播给其他人，明确开始、停止和权限失败状态。
- 每人音量范围 0–100%，按账号和远端用户保存本机偏好；全局音量与每人音量组合，静音不覆盖原偏好。
- 按键说话提供可配置快捷键，输入框聚焦时不触发；窗口失焦、离开房间或连接中断时释放按键状态。浏览器内快捷键不承诺系统全局生效。
- 显示发言者、静音、断线和共享状态，颜色同时配合图标或文字。
- 增加影院模式：收起周边导航，可切换共享画面；保留静音、退出和返回入口，视频控制条继续保持简洁。
- 诊断面板按需展示 RTT、丢包、码率、收到帧和 ICE 路径；区分收到媒体、解码与播放，无法获取的指标显示不可用。

验收：挂断或切频道后旧异步回调不恢复连接；测试结束设备资源释放；每人音量互不影响；按键失焦不持续发送；影院模式可恢复；真实两台设备验证声音与画面，单元测试不能替代实际通话验收。

## 阶段 4：社区身份与成员引导

实施状态：第八批已完成社区首页、横幅与头像本地裁切、资料编辑、欢迎规则与推荐频道，以及服务端权限控制的公告频道。资料保存使用可选编辑基线版本保护并发，当前界面提供保存失败重试和冲突后手动重新加载；旧调用可以省略版本。547 项测试、58 项界面构建检查、构建与状态/工具 TypeScript 检查通过，三账号实际页面及聊天、语音、投屏回归通过。

- 服务器横幅与头像统一裁切、上传限制、占位和移动端显示。
- 欢迎页展示介绍、规则与推荐频道，支持管理员编辑；已有服务器无配置时保持可用默认页面。
- 公告频道通过频道类型和权限控制发送，避免仅靠前端隐藏按钮。
- 公共资料、推荐频道与频道事件沿用服务器级 `viewChannel` 权限过滤；当前没有独立的逐频道 ACL。语音推荐只导航，不自动入房。
- 频道静音、仅提及与全部消息的应用内通知设置已在阶段 2 落地；用户主动开启的浏览器系统通知尚未新增，保留为后续可选增强。

验收：管理员和普通成员权限区分正确；无横幅、长名称与窄屏不破坏布局；新成员能完成加入、读规则、选频道的路径。

语音六个控制器已在第九、十批完成拆分，完整 Vue 模板类型检查在第十一批接通；第十二批完成 v1.0.9 本地打包与隔离升级验证。后续独立验收实体设备通话、共享选择器和真实网络；真实旧安装升级及 GitHub 发布仍为单独步骤。

## 阶段 5：后续扩展

私聊、小组聊天、投票、活动报名和音乐功能按实际使用反馈独立设计。私聊需要单独的数据模型、授权、屏蔽机制与通知链路；音乐需要评估媒体来源和传输成本。多人大房间是否采用 SFU，以实际带宽、CPU 和连接质量测试决定。

## 首版实施顺序与交付物

1. 完成阶段 0 基础修复并保留针对性回归验证。
2. 制作主聊天页桌面、移动端及消息状态预览；确定视觉变量与组件状态。
3. 交付消息分组、滚动锚点、输入草稿与统一提示。
4. 交付发送幂等、失败重试、重连补拉和阅读游标。
5. 进行视觉与双客户端验证，再进入阶段 2。

每批保留可独立检查的改动和验收记录。第一阶段不绑定 SQLite、SFU、音乐或第三方账号集成；这些按依赖分别交付。工期在拆出实际任务并完成首个预览后估算。

## 验证与发布要求

- 界面检查至少覆盖 1440×900、1024×768、390×844 和 360×800，长昵称、长文件名、长消息和空频道。
- 关键交互支持键盘、可见焦点与减少动画；触摸主要操作目标建议至少 44×44px。
- 前端改动按 AGENTS.md 执行 `npm run check:frontend`，包含严格 Vue 模板及 Vite 配置类型检查、生产构建与界面规则验证；单独检查类型使用 `npm run typecheck`。
- 后端按改动运行消息、权限、上传与 WebSocket 测试；新机制验证幂等、并发、断线、越权和旧数据兼容。
- 数据结构变化提供默认值、升级路径和迁移前备份；阅读标记、回应和置顶不能因升级丢失。
- 源码工作在 Z80Z-chat-build；开发完成并验证后再生成分发产物，安装版通过正式升级流程更新。
- 记录实测浏览器与设备、已验证内容和未验证边界；没有测量数据时不宣称支持人数或端到端延迟。
